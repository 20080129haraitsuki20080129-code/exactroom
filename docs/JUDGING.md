# 判定仕様(詳細)

「厳密に」とは何を指すのか、どこまでできてどこからできないのかを明確にします。

## 3 値判定の定義

| 判定 | 定義 |
| --- | --- |
| **AC** | 模範解答 M と答案 S について `M = S` を**記号的に証明できた** |
| **WA** | `M ≠ S` を**記号的に証明できた** |
| **判定保留** | どちらも証明できなかった |

「証明できた」とは、下に挙げる**数値近似を含まない手続き**のいずれかが成立したことを指します。
浮動小数点数・`evalf` / `N`・区間演算・乱数による一致判定は**一切使いません**。

---

## 使っている判定手法

### 0 であることの証明

1. 構文的に `S.Zero` と一致する。
2. SymPy の `expr.is_zero is True`。
   これは仮定システム上の記号的な導出からのみ真になります。
3. 次の厳密変形のいずれかで `0` に落ちる(式のコストに応じて適用範囲を制限):

   `cancel(together(·))`, `expand`, `radsimp`, `sqrtdenest`, `simplify`,
   `trigsimp(expand_trig(·))`, `logcombine(expand_log(·))`,
   `powsimp(expand_power_exp(·))`, `factor`, `combsimp(expand_func(·))`

### 0 でないことの証明

| # | 手法 | 数学的根拠 |
| --- | --- | --- |
| 1 | 有理数なら直接比較 | 自明 |
| 2 | `is_irrational is True` | 0 は有理数。無理数は 0 ではない |
| 3 | `is_rational is False` | 同上 |
| 4 | `is_real is False` | 0 は実数。実数でなければ 0 ではない |
| 5 | 積の各因子が 0 でない | 体(整域)に零因子はない |
| 6 | 冪の底が 0 でなく指数が有限 | 同上 |
| 7 | √ の Q 上一次独立性 | 相異なる平方因子のない正整数 m に対し `{√m}` は Q 上一次独立。`I` は実部/虚部として別の基底に分ける |
| 8 | 有理関数の係数 | 自由変数を生成元とする多項式に直し、係数が 1 つでも 0 でなければ零多項式ではない。体が無限なので恒等的に 0 にはならない |
| 9 | 厳密値の代入 | 有理数や `π/6` などの**厳密値**を代入し、得られた定数に 1〜8 を適用。代入値は**記号に付けた仮定(正・実数など)を満たすものだけ**を使う |
| 10 | 分数の分子 | `together` して分子が 0 でなく分母が有限なら、全体も 0 でない |
| 11 | 対数のまとめ | `3\log 3 - \log 8 → \log(27/8)` のように `logcombine` してから 1〜8 を適用 |

### 意図的に使っていないもの

- `expr.evalf()` / `sympy.N()` / `float()` / `complex()`
- `expr.is_zero is False` や `is_positive` / `is_negative`
  — SymPy はこれらを**内部で数値評価にフォールバックして**決めることがあるため、
  「証明できた」とは言えません(`is_zero is True` の側は記号的導出のみなので使用)。
- 有理数区間による厳密な符号決定
  — これも数値近似の一種なので、要求仕様に従って採用していません。
- 乱数による多点評価

`tests/test_security.py` が AST 解析でこの制約を機械的に守らせています。

## 解答の「種類」

| kind | 例 | 判定 |
| --- | --- | --- |
| `expr` | `x^2-1` | `M - S` が 0 か |
| `rel` | `x=1`, `x \ge 2`, `0 \le x \le 1` | 下記 |
| `set` | `\{1,2\}` | 要素の照合 |
| `list` | `1, 2` | 既定は集合として、`ordered_list` なら順序込み |

### 種類が違う場合

**WA** になります。`x = 1`(方程式)と `1`(数)、`\{1,2\}`(集合)と `1`(数)は
異なる数学的対象なので、非同値が確定します。
ただし `set` と `list` は同じ「複数解」として相互比較します(`\{1,2\}` と `1,2` は AC)。

> 出題者は、解答者にどの形で答えさせたいかを「補足」欄に明記してください。

### 関係式の比較

`lhs op rhs` を `d op' 0` に正規化します。

1. **同値の証明**: 族(`=`/`≠`/`<`/`≤`)が同じで、`d_M / d_S` が
   **0 でない定数**なら同値。不等号は**正の有理数倍**のときのみ
   (負の定数倍は向きが逆になるので WA)。
2. **非同値の証明**: 厳密な代入点を並べ、**一方の関係式だけを満たす点**を探します。
   見つかればその点が非同値の証明になります。
   - 候補は、記号の仮定(正・実数など)を満たす厳密値と、
     片方の多項式の**厳密な根**(4 次以下)。
   - 真偽の判定は、等式なら「厳密に 0 か」、不等号なら
     「符号が**厳密な有理数**として確定する点」だけを採用します
     (符号決定に数値近似を使わないため)。
3. どちらも示せなければ判定保留。

> **族が違うだけでは WA にしません。**
> `x^2 \ge 0` と `x^2+1 > 0` はどちらも実数全体で恒真なので同値です。
> 「`d = 0` になる点が違う」は等式では非同値の証拠になりますが、
> 不等式では証拠になりません。

### 集合・複数解の比較

- 要素どうしの総当たり表を作ります。
- ある要素がもう一方の**全要素と非同値だと確定**したら WA。
- 全ペアの等価判定が確定したら、重複を潰したうえで両包含を確認して AC。
- 未確定のペアが残れば判定保留。
- 要素数の上限は 12。

## 実例

| 模範解答 | 答案 | 判定 | 理由 |
| --- | --- | --- | --- |
| `\frac{1}{2}` | `0.5` | AC | 小数は厳密な有理数 `1/2` |
| `\frac{1}{2}` | `\frac{2}{4}` | AC | 有理数として一致 |
| `x^2-1` | `(x-1)(x+1)` | AC | `expand` で差が 0 |
| `\sqrt{5+2\sqrt{6}}` | `\sqrt{2}+\sqrt{3}` | AC | `sqrtdenest` |
| `\sin^2x+\cos^2x` | `1` | AC | `trigsimp` |
| `\frac{x^2-1}{x-1}` | `x+1` | AC | `cancel` |
| `x=1` | `2x=2` | AC | 比が定数 2 |
| `\{1,2\}` | `1,2` | AC | 集合と複数解は相互比較 |
| `\sqrt{2}` | `1.41421356` | **WA** | `√2 − 1.41421356` は無理数 ⇒ 0 でない |
| `2\pi` | `6.28` | **WA** | `2π − 6.28` は無理数 |
| `x+1` | `x+2` | **WA** | 有理関数の係数が 0 でない |
| `x>2` | `x \ge 2` | **WA** | `x=2` が後者だけを満たす(反例点) |
| `x^2 \ge 0` | `(x-1)^2 \ge 0` | 判定保留 | どちらも恒真で同値。反例点が無いので WA にできない |
| `x=1` | `1` | **WA** | 種類が違う |
| `\ln(x^2)` | `2\ln x` | **WA**(既定) | 実数では `x<0` で異なる。`assume_positive` を ON にすると AC |
| 任意 | `\text{わかりません}` | 判定保留 | 答案を TeX として解釈できない |

## 判定保留になりやすいケース

- 超越数どうしの複雑な差(例: `\cos 1 - \sin 1` のような、SymPy が
  無理性を決定できない定数)
- 特殊関数や、上に挙げた変形で 0 に落ちない恒等式
- 計算が 8 秒を超えた場合(`JUDGE_TIMEOUT_SEC` で調整可)

判定保留は**誤りではありません**。出題者が「提出一覧」の `reason` 列を見て、
必要なら手動で採点してください。

---

## 出題時のコツ

1. **「解釈を確認」を必ず使う。** 模範解答がシステムにどう読まれるかを見てから登録します。
2. **「この問題の判定を試す」で別解を検証する。** 解答者が書きそうな形をいくつか入れて
   AC になるか確かめます。
3. **答えの形を補足欄で指定する。**
   「因数分解した形で」「有理化して」など、形を要求する問題では、
   形の違いも同値なら AC になってしまう点に注意してください
   (`x^2-1` と `(x-1)(x+1)` は AC です)。
   形を厳密に問いたい場合は、この種のシステムには向きません。
4. **対数・平方根の問題では `assume_positive` を検討する。**
5. **複素数の問題では `assume_real` を OFF に。**
   実数と仮定していると `\overline{z}` が `z` に簡約されます。
6. **近似値を正解にしたい問題には使わない。** `π` に `3.14` は WA になります。
