ExactRoom 数式の厳密自動判定

数式を厳密に自動判定します

出題者が TeX で登録した模範解答と、解答者が入力した答案が 数学的に同値かどうかを Python + SymPy で厳密に判定します。 数値近似は一切使いません。同値だと証明できたときだけ AC、 同値でないと証明できたときだけ WA、 どちらも証明できなければ 判定保留 になります。 模範解答がブラウザ側に送られることはありません。
